# 김진휘 포트폴리오

오페라 연출가 · 음악치료를 공부하는 김진휘의 포트폴리오 사이트입니다.

## 구성
| 파일 | 내용 |
|---|---|
| `index.html` | 페이지 뼈대 |
| `content.js` | 사이트에 나오는 모든 글과 공연 정보 (내용은 여기서만 고치면 돼요) |
| `style.css` | 디자인 |
| `script.js` | 화면을 그리는 코드 (이야기책, 공연 목록 필터, 프로그램북 보기) |
| `images/` | 프로필 사진, 포스터 |
| `images/programbook/` | 경력 증빙용 프로그램북 사진 (다른 분들의 얼굴은 모자이크 처리) |
| `PLAN.md` | 기획·설계서 |

## 보는 방법
`index.html`을 브라우저로 열면 돼요.

## 저작권
공연 포스터와 프로그램북의 저작권은 각 제작 기관에 있습니다.
